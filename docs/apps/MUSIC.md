# Music

## Зона ответственности

Статическая FakeTLS-заглушка для домена маскировки. Архитектурный контекст
зафиксирован в [ARCHITECTURE.md](../ARCHITECTURE.md).

## Карта компонентов

Приложение содержит только статический ответ без бизнес-логики.

## Зависимости

Доменные приложения от Music не зависят.

## Границы

Не изучать, не рефакторить и не изменять без прямого запроса пользователя.
